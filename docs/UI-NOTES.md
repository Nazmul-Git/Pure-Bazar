# PureBazar UI Notes

This summary is based on the design guidance supplied for this task. The
`ui-reference/` directory was unavailable, so unspecified visual values are
left open rather than guessed.

## Design System

- **Colors:** Primary dark slate, accent blue, white backgrounds, and neutral
	grays for borders. Exact hex values were not supplied. Status badge colors
	are used for active, pending, and success states; individual hex values are
	unspecified.
- **Typography:** Clean sans-serif, using Inter or the system UI font. Text
	sizes should respond to screen size.
- **Spacing:** No numeric spacing scale was supplied.

## Layout

- **Sidebar:** Fixed on the left.
- **Header:** Top header with a user profile menu.
- **Main area:** Content area organized with card containers.

## Components

- **Cards:** Clean, consistent padding.
- **Tables:** Row hover feedback and pagination support.
- **Forms:** Inputs and selects have a clean border radius and visible focus
	rings.
- **Modals:** Backdrop blur.
- **Buttons:** Primary, secondary, and ghost variants.
- **Badges:** Status colors for active, pending, and success.
